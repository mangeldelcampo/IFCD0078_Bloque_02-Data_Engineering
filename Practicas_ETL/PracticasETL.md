*Este repositorio es una practica de ejercicios de ETL con Azure*

| # | Laboratorio | Descripción |
| :--- | :--- | :--- |
| 1 | [Ejercicio 1: Azure SQL Database hacia ADLS Gen2](/Practicas_ETL/1.Azure_SQL_Database_hacia_ADLS_Gen2/ReadmeETL.md) | **Implementación de una canalización de datos EL** (Extract-Load) utilizando Azure Data Factory para transferir información desde una base de datos relacional (Azure SQL Database) hacia la capa Raw de Azure Data Lake Storage Gen2.   **Tecnologías**: Azure SQL Database, Azure Data Factory (ADF), Azure Data Lake Storage Gen2 (ADLS Gen2), Managed Identity. **Aspectos clave:** Creación de vistas de extracción desnormalizadas en T-SQL, particionado dinámico de rutas en Data Lake por fecha de carga (fecha_carga=YYYY-MM-DD), autenticación segura mediante Managed Identity y orquestación con triggers programados. |
| 2 | [Design and implement a dimensional model](./Laboratorios/2.Design_and_implement_a_dimensional_model/readme2.md) | En este laboratorio, diseñará e implementará un modelo dimensional de esquema en estrella en un Fabric Warehouse, creando tablas de hechos y dimensiones con relaciones de clave externa. Ejecutará consultas analíticas para agregar datos de ventas en múltiples dimensiones e implementará patrones de dimensión de cambio lento (SCD) de tipo 1 y tipo 2 para manejar datos que cambian con el tiempo. |
| 3 | [Design scalable semantic models](./Laboratorios/3.NOMBRE_LABORATORIO/readme3.md) | En este laboratorio, diseñará un modelo semántico para escalabilidad en el servicio Microsoft Fabric. Se conectará a los datos de Lakehouse mediante Direct Lake, creará relaciones de esquema en estrella, creará un grupo de cálculo para inteligencia temporal y configurará ajustes que admitan grandes conjuntos de datos y consumo simultáneo. |
